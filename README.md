# Superstore Sales & Profit Analysis Dashboard
 
## 🎯 Project Goal
 
The primary objective of this project is to analyze enterprise sales data to identify key revenue drivers, evaluate regional performance, and uncover hidden profit margin bleed. By transforming raw transactional data into an interactive dashboard, this tool empowers stakeholders to make data-driven decisions regarding inventory pricing and regional strategy.
 
## 🛠️ Tools & Technologies Used
 
- **Power BI** — Data visualization, interactive dashboard design, and ETL (Extract, Transform, Load) using Power Query.
- **DAX (Data Analysis Expressions)** — Engineered custom measures for calculating Total Sales, Total Profit, Profit Margin %, and YoY Growth %, along with conditional formatting logic.
- **Data Modelling** — Built a relational data model (Star Schema) connecting Fact and Dimension tables for accurate filtering.
## 💡 Key Business Insights
 
1. **Hidden Margin Bleed** — While sub-categories like *Tables* and *Bookcases* drive significant top-line revenue, conditional formatting exposes massive net losses, pinpointing deep pricing or supply chain inefficiencies.
2. **Regional Disparities** — Geographic mapping of the United States isolates high-volume sales zones while identifying underperforming state territories that require strategic intervention.
3. **Seasonal Trend Volatility** — Month-over-month tracking reveals distinct seasonal spikes and dips in both total sales and net profit, providing actionable intel for future inventory forecasting.
